## Demo Flow (5 minutes)

1. **Public Booking** (mobile view)
   - Open /book
   - Select doctor → date → slot
   - Complete booking → get token

2. **⚡ Real-Time Magic**
   - Open /doctor in second tab
   - Book from /book → watch doctor dashboard update live

3. **Reception Check-in**
   - Login as receptionist
   - Check-in patient → assign queue

4. **Consultation**
   - Login as doctor
   - Start consultation → write prescription

5. **Pharmacy**
   - Login as pharmacist
   - Dispense prescription

6. **Billing**
   - Auto-generated bill
   - Mark as paid

7. **Patient Portal**
   - Login with phone
   - View appointments, prescriptions, bills

8. **Analytics**
   - Login as admin
   - View revenue, footfall, doctor performance

## Key Selling Points

- ⚡ Real-time updates (no refresh)
- 🔒 Multi-tenant (each clinic isolated)
- 📱 Mobile-first
- 💰 Payment ready (Razorpay)
- 📊 Analytics
- 🔔 Notifications (Email/SMS/WhatsApp)
